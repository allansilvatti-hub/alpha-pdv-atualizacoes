# Alpha PDV - Atualizacoes

Repositorio publico apenas com os **instaladores** do Alpha PDV (Alpha Vision Consultoria).
O codigo-fonte e privado.

Os sistemas instalados nos clientes buscam aqui as novas versoes e se atualizam sozinhos.
Para instalar manualmente, baixe o arquivo **AlphaPDV-Setup-x.y.z.exe** da versao mais recente em *Releases*.
